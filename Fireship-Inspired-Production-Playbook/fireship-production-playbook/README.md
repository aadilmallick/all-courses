# Make sharp software videos

**A focused Fireship-inspired production course for Aadil.** Read [the course](course.html), then keep [the production checklist](playbook.md) beside your editor. Edition: 13 November 2026.

The target is a clear, original 90–150-second developer explainer, then a 3–5-minute version. Your confirmed schedule is 8–10 hours a week. This is six weeks of practice, followed by a repeatable two-week production cycle. It is a skill progression, not a promise of matching an experienced creator in six weeks.

## The shortest path

1. Pick **one** editor. Default: free DaVinci Resolve. If you already use Premiere, stay there and use the translation notes. Do not learn both at once.
2. Make a 20-second audio edit before buying anything.
3. Learn seven reusable editing moves, each for a specific communication job.
4. Finish one original short explainer, then improve it through two revisions.
5. Repeat the production checklist with a new topic.
