2. Form B minus A component by component, then square and add.
3. Use cosine for the horizontal component and sine for the vertical.
4. Normalize only after adding the components.
5. Perpendicular vectors have zero dot product. Check cross-product order.
6. Water-relative and river velocities add as vectors.
7. This is a rotation of axes, so use the passive transformation in the chapter.
