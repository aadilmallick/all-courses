# 09. Hints

1. Frequency is unchanged at the stationary interface. Apply Snell's law and then divide the vacuum wavelength by index.
2. Solve the reciprocal lens equation with signs before interpreting the image.
3. Interference maxima use slit separation; envelope zeros use slit width. Their ratio identifies a missing order.
4. Set the interference cosine to $-1$ and $+1$ for the extrema.
5. The first polarizer halves unpolarized intensity. Each following angle is relative to the preceding polarizer.
6. Square the amplitude reflection coefficient for normal incidence. Total internal reflection requires incidence from the higher index.
7. The mirror belongs to a round-trip arm, so its motion changes the path twice.
8. Match amplitudes with the geometric-mean index, then set optical thickness equal to a quarter vacuum wavelength.
