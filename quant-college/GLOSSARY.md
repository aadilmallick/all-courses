# Working glossary and notation

| Term | Meaning in this program |
|---|---|
| Simple return | Ending value plus timed distributions, divided by initial value, minus one, under the stated convention. |
| Log return | Natural logarithm of a positive gross return; additive over consecutive holding periods. |
| Basis point | 0.0001 as a decimal rate; 0.01 percentage points. |
| Discount factor | Current price of a specified unit payment at a future date under a defined credit/collateral model. |
| Yield | A rate summarizing a price under a particular cash-flow and compounding convention. |
| Duration | A local interest-rate sensitivity or present-value-weighted time, with the exact convention stated. |
| Convexity | Curvature; in bonds, a normalized second yield derivative under a specified shift. |
| Expected value | Probability-weighted mean under a named model. |
| Variance | Expected squared deviation from a mean, when finite. |
| Covariance | Expected product of centered variables; measures linear co-movement. |
| Correlation | Covariance divided by positive standard deviations. |
| Independence | Joint probabilities factor; stronger than zero covariance in general. |
| Conditional expectation | Probability-weighted prediction given an information set. |
| Parameter | A population or model quantity being estimated. |
| Estimator | A rule mapping data to an estimate. |
| Standard error | Estimated sampling spread of an estimator. |
| Confidence interval | Output of a repeated-sampling coverage procedure under assumptions. |
| Credible interval | A region with specified posterior probability under a Bayesian model. |
| Identification | Uniqueness of a target from population observables under assumptions. |
| Endogeneity | Regressors related to structural errors in a way violating the intended identifying condition. |
| Instrument | A variable satisfying relevance and specified exogeneity/exclusion restrictions for a target. |
| GMM | Estimation by weighted discrepancies in sample moment restrictions. |
| M-estimation | Estimation by minimizing an average criterion. |
| Stationarity | Invariance of specified distributional or second-order properties under time shifts. |
| Ergodicity | Conditions permitting relevant time averages to recover population quantities. |
| Innovation | An unpredictable model residual relative to a specified information set. |
| Unit root | A dynamic root producing nonstationary persistence under the stated model. |
| Cointegration | A stationary linear combination of suitably integrated nonstationary series. |
| Filtering | State estimation using observations through the current date. |
| Smoothing | State estimation using later observations too. |
| Spectrum | Frequency-domain description of second-order stationary variation. |
| Long-run variance | Variance plus accumulated autocovariances governing mean uncertainty under suitable limits. |
| Positive semidefinite | A symmetric matrix with nonnegative quadratic form in every direction. |
| Rank | Number of independent matrix directions. |
| Condition number | A scale-aware measure of sensitivity, specified for a norm. |
| Convex problem | Convex objective minimized over a convex feasible set in the standard formulation. |
| Duality gap | Difference between suitable primal and dual feasible objective bounds. |
| KKT conditions | Feasibility, stationarity, multiplier signs, and complementary slackness. |
| Filtration | Increasing mathematical representation of available information. |
| Adapted | Current value determined by current information. |
| Martingale | Integrable process whose conditional future mean equals its present value. |
| Brownian motion | Continuous process with independent Gaussian increments of variance equal to elapsed time. |
| Quadratic variation | Limit of squared increments under an appropriate partition convention. |
| Itô correction | Surviving second-order term caused by stochastic quadratic variation. |
| P and Q | Physical outcome model and pricing probability measure, respectively. |
| Replication | State-by-state matching of a claim using feasible traded positions. |
| Delta and gamma | First and second model-price sensitivities to underlying price. |
| Implied volatility | Volatility input matching a quote in a specified pricing model. |
| Bellman equation | Recursion for optimized continuation value under a dynamic model. |
| VaR | Loss quantile at a specified probability, horizon, and convention. |
| Expected shortfall | Quantile-integrated worst-tail loss average under the stated definition. |
| Drawdown | Decline from a prior wealth peak; depth and duration are different. |
| Turnover | Traded fraction under an explicitly stated one-way or full-sum convention. |
| Capacity | Performance feasibility as trading scale grows. |
| Leakage | Information entering a model that was unavailable in the claimed prediction setting. |
| Generalization | Behavior on new relevant data beyond fitting observations. |
| Calibration | Agreement between forecast probabilities and corresponding event frequencies. |
| Regularization | A restriction or penalty trading fit against stability or complexity. |
| MCMC | Dependent simulation targeting a distribution under convergence conditions. |
| Synthetic fixture | Generated data with controlled properties for implementation checks, not market evidence. |
