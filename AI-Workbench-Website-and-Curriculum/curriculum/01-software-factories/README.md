# Software factories & agent boards


Learn the loop from a bounded task to a reviewed change, then coordinate multiple tasks through milestones and workspaces. Start with Codex or Claude Code; add a board or orchestrator when the work actually needs it.

## The learning sequence

Begin with [Foundations](../reference/foundations.md), then choose the first tool that fits your platform and intended work. Each tool below has a separate full chapter with prerequisites, worked examples, troubleshooting, an optional application, and direct sources.

| Tool | What you will study | Practice estimate |
| --- | --- | --- |
| [Codex](01-codex.md) | Local and cloud coding tasks with reusable environments and evidence-based review. | 3–5 hours |
| [Claude Code](02-claude-code.md) | Terminal and editor agent workflows with project instructions, skills, tool connections, checkpoints, and worktrees. | 4–6 hours |
| [Cursor](03-cursor.md) | Interactive coding agents, isolated cloud development environments, and event-driven automations. | 4–6 hours |
| [GitHub Copilot](04-github-copilot.md) | Repository-native agent sessions, cloud execution choices, pull-request review, and automations. | 4–6 hours |
| [Devin](05-devin.md) | Delegate a verifiable bug fix, prepare the environment and review a focused patch with evidence. | 4–6 hours |
| [Factory Droid & Missions](06-factory.md) | Plan, coordinate, and validate bounded multi-feature agent work with milestone evidence. | 4–6 hours |
| [OpenHands](07-openhands.md) | Compose an agent control surface, model access, and local or remote execution backends. | 4–6 hours |
| [Paradev (formerly Superset)](08-paradev.md) | A task board and workspace layer for launching and reviewing parallel coding agents. | 4–6 hours |

## Make the comparison useful

Choose one realistic task and keep its input and acceptance criteria fixed while comparing tools. Read [Compare & Choose](../reference/compare.md) for selection dimensions, [Learning paths](../reference/learning-paths.md) for reading order, and [Cross-tool projects](../reference/projects.md) for scoped applications.

Capabilities, account access, and service lifecycles change. Check each chapter's current sources and the [ecosystem change notes](../reference/watchlist.md) before installing packages or spending on a trial. The estimate includes optional practice; reading alone is shorter.
