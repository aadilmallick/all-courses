# Voice agent tooling


Understand conversation turns, audio transport, model decisions, tools, and telephony. Compare managed platforms with custom frameworks using the same synthetic conversation scenarios.

## The learning sequence

Begin with [Foundations](../reference/foundations.md), then choose the first tool that fits your platform and intended work. Each tool below has a separate full chapter with prerequisites, worked examples, troubleshooting, an optional application, and direct sources.

| Tool | What you will study | Practice estimate |
| --- | --- | --- |
| [LiveKit Agents](01-livekit.md) | Code-centered voice agents with room/session abstractions and cloud deployment. | 3–5 hours |
| [Pipecat](02-pipecat.md) | Compose realtime voice applications through pipelines, processors, and frames. | 3–5 hours |
| [Vapi](03-vapi.md) | Managed voice orchestration with configurable providers, web calling, and server tools. | 3–5 hours |
| [Retell AI](04-retell.md) | Managed voice agents with prompt and flow designs, custom functions, and testing workflows. | 3–5 hours |
| [ElevenLabs Agents · ElevenAgents](05-elevenlabs.md) | Voice-oriented agent platform with knowledge, tools, client embedding, and evaluation. | 3–5 hours |
| [OpenAI Realtime API](06-openai-realtime.md) | Speech-to-speech sessions with tools, turn detection, and browser/server transports. | 4–6 hours |
| [Deepgram Voice Agent API](07-deepgram.md) | Managed listening, reasoning integration, and speech over a WebSocket conversation. | 3–5 hours |
| [Twilio ConversationRelay](08-twilio-conversationrelay.md) | Telephone speech handling connected to your own text-oriented agent server. | 4–6 hours |

## Make the comparison useful

Choose one realistic task and keep its input and acceptance criteria fixed while comparing tools. Read [Compare & Choose](../reference/compare.md) for selection dimensions, [Learning paths](../reference/learning-paths.md) for reading order, and [Cross-tool projects](../reference/projects.md) for scoped applications.

Capabilities, account access, and service lifecycles change. Check each chapter's current sources and the [ecosystem change notes](../reference/watchlist.md) before installing packages or spending on a trial. The estimate includes optional practice; reading alone is shorter.
