# Compare and choose


## Make a shortlist around one real task

There is no useful universal winner across these categories. A voice API and a sandbox are complementary layers. A desktop workspace manager and a managed software agent divide responsibility differently. A footage generator and an interactive avatar serve different communication needs. Use the following tables to choose a trial, then read the linked chapters for sources, setup, and limitations.

These comparisons express the curriculum's selection judgment. They are not measured performance rankings, guaranteed feature matrices, or price quotations. Check your account and current documentation before purchasing access.

## A fair trial protocol

Fix the input, baseline, and acceptance criteria. Record the exact tool mode and account capability you used. Make one small trial, inspect the result, then repeat with a useful variation. Compare accepted quality, setup, human attention, recoverability, and cost units. Keep failures in the record; excluding them makes the comparison less useful.

Before adopting a tool, answer: can my team operate it, can we export the important artifacts, can we recover from a failed run, and can we move away if the service changes? The [lifecycle notes](watchlist.md) show why these questions belong in an ordinary product decision.
