Learn to turn an approved brief into coherent footage, a scripted presenter, or an interactive audiovisual experience. Check model and API lifecycle before following older examples.

## The learning sequence

Begin with [Foundations](/foundations/), then choose the first tool that fits your platform and intended work. Each tool below has a separate full chapter with prerequisites, worked examples, troubleshooting, an optional application, and direct sources.

| Tool | What you will study | Practice estimate |
| --- | --- | --- |
| [Runway](/video/runway/) | Direct short generated shots and assemble reliable release-video assets. | 3–5 hours |
| [Google Flow, Veo and Gemini video](/video/google-veo-flow/) | Learn the filmmaking application and distinguish current Google video API routes. | 4–6 hours |
| [Kling AI](/video/kling/) | Direct reference-driven clips and control key moments with a clear asset-role plan. | 3–5 hours |
| [Luma and Dream Machine](/video/luma/) | Organize boards and compare still animation, keyframes and source-footage transformation. | 3–5 hours |
| [HeyGen](/video/heygen/) | Build scripted avatar lessons and learn the current v3 developer workflow. | 3–5 hours |
| [Synthesia](/video/synthesia/) | Create maintainable avatar training from approved scripts and reusable templates. | 3–5 hours |
| [Tavus](/video/tavus/) | Build and evaluate a narrow interactive video tutor using current PAL terminology. | 4–6 hours |
| [D-ID](/video/d-id/) | Learn asynchronous avatar rendering and the separate lifecycle of real-time agents. | 4–6 hours |

## Make the comparison useful

Choose one realistic task and keep its input and acceptance criteria fixed while comparing tools. Read [Compare & Choose](/compare/) for selection dimensions, [Learning paths](/learning-paths/) for reading order, and [Cross-tool projects](/projects/) for scoped applications.

Capabilities, account access, and service lifecycles change. Check each chapter's current sources and the [ecosystem change notes](/watchlist/) before installing packages or spending on a trial. The estimate includes optional practice; reading alone is shorter.
