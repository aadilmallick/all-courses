Learn the loop from a bounded task to a reviewed change, then coordinate multiple tasks through milestones and workspaces. Start with Codex or Claude Code; add a board or orchestrator when the work actually needs it.

## The learning sequence

Begin with [Foundations](/foundations/), then choose the first tool that fits your platform and intended work. Each tool below has a separate full chapter with prerequisites, worked examples, troubleshooting, an optional application, and direct sources.

| Tool | What you will study | Practice estimate |
| --- | --- | --- |
| [Codex](/factories/codex/) | Local and cloud coding tasks with reusable environments and evidence-based review. | 3–5 hours |
| [Claude Code](/factories/claude-code/) | Terminal and editor agent workflows with project instructions, skills, tool connections, checkpoints, and worktrees. | 4–6 hours |
| [Cursor](/factories/cursor/) | Interactive coding agents, isolated cloud development environments, and event-driven automations. | 4–6 hours |
| [GitHub Copilot](/factories/github-copilot/) | Repository-native agent sessions, cloud execution choices, pull-request review, and automations. | 4–6 hours |
| [Devin](/factories/devin/) | Delegate a verifiable bug fix, prepare the environment and review a focused patch with evidence. | 4–6 hours |
| [Factory Droid & Missions](/factories/factory/) | Plan, coordinate, and validate bounded multi-feature agent work with milestone evidence. | 4–6 hours |
| [OpenHands](/factories/openhands/) | Compose an agent control surface, model access, and local or remote execution backends. | 4–6 hours |
| [Paradev (formerly Superset)](/factories/paradev/) | A task board and workspace layer for launching and reviewing parallel coding agents. | 4–6 hours |

## Make the comparison useful

Choose one realistic task and keep its input and acceptance criteria fixed while comparing tools. Read [Compare & Choose](/compare/) for selection dimensions, [Learning paths](/learning-paths/) for reading order, and [Cross-tool projects](/projects/) for scoped applications.

Capabilities, account access, and service lifecycles change. Check each chapter's current sources and the [ecosystem change notes](/watchlist/) before installing packages or spending on a trial. The estimate includes optional practice; reading alone is shorter.
