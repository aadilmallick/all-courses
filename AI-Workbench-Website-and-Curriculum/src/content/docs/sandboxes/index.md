Understand where agents execute, which state survives, and how to export evidence before cleanup. Distinguish programmatic execution infrastructure from remote developer workspaces.

## The learning sequence

Begin with [Foundations](/foundations/), then choose the first tool that fits your platform and intended work. Each tool below has a separate full chapter with prerequisites, worked examples, troubleshooting, an optional application, and direct sources.

| Tool | What you will study | Practice estimate |
| --- | --- | --- |
| [E2B](/sandboxes/e2b/) | An execution SDK for agent code, analysis programs, and task-scoped Linux sessions. | 3–5 hours |
| [Daytona](/sandboxes/daytona/) | Programmable agent workspaces with process execution, sessions, reusable environments, and lifecycle controls. | 4–6 hours |
| [Modal Sandboxes](/sandboxes/modal/) | Programmable isolated processes within a broader cloud-compute platform, with Python supervision and explicit networking. | 4–6 hours |
| [Freestyle](/sandboxes/freestyle/) | Durable Linux VMs for long-running agent work, with deliberate pause/resume, snapshots, and network policy. | 4–6 hours |
| [CodeSandbox SDK](/sandboxes/codesandbox/) | Programmatically create inspectable project environments with file operations, commands, and application previews. | 4–6 hours |
| [Cloudflare Sandboxes](/sandboxes/cloudflare-sandbox/) | Worker-controlled execution using Linux Containers or Dynamic Workers, with a current 1.0 versus legacy SDK distinction. | 5–7 hours |
| [GitHub Codespaces](/sandboxes/github-codespaces/) | Repository-centered development environments for reproducible human and agent collaboration. | 3–5 hours |
| [Coder](/sandboxes/coder/) | Self-hosted workspace infrastructure with templates and multiple native or third-party agent execution paths. | 5–7 hours |

## Make the comparison useful

Choose one realistic task and keep its input and acceptance criteria fixed while comparing tools. Read [Compare & Choose](/compare/) for selection dimensions, [Learning paths](/learning-paths/) for reading order, and [Cross-tool projects](/projects/) for scoped applications.

Capabilities, account access, and service lifecycles change. Check each chapter's current sources and the [ecosystem change notes](/watchlist/) before installing packages or spending on a trial. The estimate includes optional practice; reading alone is shorter.
