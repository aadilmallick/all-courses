## Actual browser behavior

Specific inspected OQLF grammar pages include [conditional past](https://vitrinelinguistique.oqlf.gouv.qc.ca/24141/la-grammaire/le-verbe/temps-grammaticaux/conditionnel/conditionnel-passe-et-plus-que-parfait-du-subjonctif), [subjunctive or indicative after conjunctions](https://vitrinelinguistique.oqlf.gouv.qc.ca/24238/la-grammaire/le-verbe/modes/subjonctif/subjonctif-ou-indicatif-apres-les-subordonnants-composes), [pronominal participle agreement](https://vitrinelinguistique.oqlf.gouv.qc.ca/22942/la-grammaire/le-verbe/accord-du-participe-passe/avec-lauxiliaire-etre/accord-du-participe-passe-des-verbes-occasionnellement-pronominaux), [expletive ne](https://vitrinelinguistique.oqlf.gouv.qc.ca/22467/la-syntaxe/la-negation-et-la-restriction/constructions-avec-un-ne-expletif), and [temporal conditional](https://vitrinelinguistique.oqlf.gouv.qc.ca/24138/la-grammaire/le-verbe/temps-grammaticaux/conditionnel/valeur-temporelle-du-conditionnel). The grammar reference cites further public-language sources for adverbs and tout; it identifies an indexed-only CCDMD extract.

The website is a static client-side application. The course does not send your answers or recordings to a course server. Progress is stored in localStorage and can be exported. Hosted delivery still uses the hosting provider’s normal access infrastructure; this statement concerns learning-tool data, not all network traffic generated by opening a website.

Text-to-speech chooses an installed French-language voice. The voice menu identifies device versus online voices using the browser’s localService flag. Device providers control availability and audio quality. These voices are synthetic; no human-native recording library is included. No French voice is replaced silently with an English one. Ordinary selected-text menus offer pronunciation; editable-field context menus remain native. The visible reading button and Alt+L are alternatives.

Recording uses microphone permission and local playback. Dictation requires the browser to expose local recognition and a French pack; it explicitly sets processLocally to true. The optional AI coach uses the current LanguageModel interface and checks French text plus audio support before opening a session. A missing API, model, pack, permission, or hardware capability produces a useful message. The app does not call a remote AI service as a substitute. Model downloads need network access and device storage. These optional features require actual testing on the learner’s supported desktop Chrome device.

Reference matches and word overlap are narrow computations. They do not establish pronunciation accuracy, spontaneity, interpersonal skill, or C1 proficiency. AI feedback is tentative, may misunderstand audio, and may make linguistic mistakes. Use the chapter rubrics and human feedback for broader judgments.

## Scope and reproducibility

The book covers the main grammatical system through advanced reading and production, including literary forms for recognition. It cannot include every specialist term, idiom, regional feature, or historical usage. Its finite vocabulary bank is a curated core. The curriculum includes a continuing vocabulary-acquisition method and substantial independent input time. All level claims refer to intended learning scope, not outcomes independently measured in learners.

The package includes authored source, data, a single-volume book, generated chapter pages, and a static build. Dependencies are pinned with a lockfile. Source code notices for redistributed build dependencies are included in THIRD-PARTY-NOTICES.md. Canonical text is assembled without copying unlicensed source material. See verification.md for what was run and what remains untested.
