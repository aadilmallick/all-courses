# Verification and practical limits

Prepared 13 November 2026. See `verification.json` for measured output and `check.cjs` for the checks.

## Completed

- Built one continuous Markdown guide and an offline HTML reader from eight canonical chapter files and seven supporting sections.
- Built separate start-today and production-checklist HTML pages.
- Checked chapter presence, balanced Markdown fences, local file references, unique HTML IDs, and internal navigation targets.
- Checked 90 contiguous daily actions, all six release targets, and all six 48–72-hour review checkpoints within the plan.
- Checked 510 minutes per complete week and 6,510 minutes total; checked the stated basic production and equipment arithmetic.
- Reviewed the distinction between observed creator techniques and original workflow recommendations. Full source transcripts and source frames are not included.
- Recorded source dates, partial inspection, a repeat-fetch failure, and unavailable service details in sources.md.

The eight chapters contain 11,963 whitespace-separated words in this edition. The assembled guide contains 19,433 whitespace-separated words including tables, plans, references, and templates. These are word counts, not tokenizer measurements or a claim that length proves teaching quality. This deliverable is a focused complete practical guide; no per-chapter token minimum was requested for this guide.

## Not verified by execution or visual inspection

- The available browser rejected local-file preview in this environment. No alternate route was used. HTML layout, small-screen rendering, printing, and the SVG diagram were not visually inspected.
- No real camera/microphone compatibility test, hands-on equipment comparison, Resolve editing session, video export, caption generation, or YouTube publication was performed. The procedures are instructions for the learner.
- Public creator research sampled selected frames and opening transcripts, not every frame or the creators’ private production processes.
- External links were researched but are not guaranteed to remain available. Account-specific Studio features were not tested.
- Growth, audience fit, conversion, and income are not forecast or guaranteed.
