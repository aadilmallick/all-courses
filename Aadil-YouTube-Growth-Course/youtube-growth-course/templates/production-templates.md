## Spoken structure

1. Show the result or failure within the opening.
2. State what the viewer will be able to do and its boundary.
3. Introduce the smallest example and missing prerequisite.
4. Work through the change with visible intermediate states.
5. Retest; distinguish what improved from what remains unproved.
6. Deliver the payoff and one relevant continuation.

Read the narration aloud. Mark breaths, screen changes and silent demonstration sections. Estimate runtime in the script lab, then rehearse the actual sequence. Do not add demonstration time twice.

## Recording checks

Use a dedicated browser profile and synthetic data. Confirm microphone, capture source, readable font, notifications, storage and container compatibility. Make a 30-second sample, import it into the editor and listen back. Record in small sections with handles before/after the action. Keep original footage and a separate working copy. If camera footage uses different color or frame behavior, verify a short mixed export before recording everything.

## Editing passes

- Argument: remove material that does not support the promised outcome.
- Evidence: align narration, code and visible result; show intermediate states.
- Comprehension: use restrained labels, readable crops and diagrams.
- Sound/picture: consistent comfortable speech and believable camera exposure.
- Delivery: corrected technical captions, full export inspection, tested links.

Net time saved equals manual total minus all AI-side time. Separate unattended processing from owner work where it matters. Do not retain a tool simply because the first generated output arrives quickly.

## Publication and review

Before publishing: promise fulfilled, source claims current, media rights recorded, sound comfortable, code readable, captions corrected, private data absent, one next step working, required settings reviewed. After publishing: record date, video age, traffic sources, actual metrics and uncertainty. Write one observation, competing explanations and one change for the next production cycle.
