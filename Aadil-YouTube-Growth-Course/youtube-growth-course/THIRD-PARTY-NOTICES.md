# Third-party material

The chapter prose, illustrative data, templates, diagrams and companion calculations were authored for this course. No external creator footage, thumbnails, transcripts, paid course materials, full manuals or original project source documents are redistributed. External links retain their respective rights and terms.

For reproducible HTML assembly this package includes **Marked17.0.5**, an MIT-licensed Markdown parser. Its unmodified ESM distribution is `vendor/marked.esm.mjs` and its complete license is `vendor/marked-LICENSE.md`. Renaming the extension enables direct Node import without a package manifest. The original distribution header is retained. Marked is used during rebuilding; the finished book.html does not load the parser or any remote script.

The companion is original dependency-free JavaScript and runs without third-party packages or external services. Node.js and a modern browser are runtime prerequisites, not bundled binaries. The build environment used Node26.7.0. No software is installed by opening this package.
