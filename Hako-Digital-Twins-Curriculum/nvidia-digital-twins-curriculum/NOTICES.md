# Provenance and distribution notes

The explanatory prose, teaching examples, synthetic fixtures, and browser experiments were authored for this curriculum. Primary documentation is linked for verification and further study. No full copyrighted documentation extracts, NVIDIA binaries, vendor robot assets, downloaded models, or original private DOCX files are redistributed.

API names and small conventional usage patterns appear where necessary to teach interoperability. No third-party package source is bundled. Optional dependencies are obtained separately under their respective licenses. `book.html` is rendered from the authored Markdown using Marked 17.0.5; the parser itself is not included in the runtime artifact.

No general open-source license is assigned to the user's private role context or supplied materials. Review before sharing externally. Company-specific planning numbers are attributed context, not verified public performance claims.
