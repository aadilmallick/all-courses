Partial inspection is identified below; an index or search result is not treated as a fully read book. No full copyrighted source is redistributed. The vocabulary is curated, not a published frequency ranking. Native Hyderabadi editorial and pronunciation review remains outstanding.

## Browser and audio behavior

The course text and quizzes are static and client-side. Microphone recording needs HTTPS or localhost and browser permission. Chrome’s current Prompt API lists English, Japanese, Spanish, German and French for text; it does not list Urdu. The optional AI coach therefore works with an English reflection on learning, not an Urdu transcript or pronunciation grade. Language-model and recognition availability are checked on your device; downloads start only through their buttons.

System Urdu/Hindi voices vary by device. Where a voice exists, mapped machine-only native spelling supplies pronunciation input while the interface stays Roman. Some voices are network services; their local/provider status is shown. No recorded native audio ships with this edition. Uploaded family audio is stored locally and takes priority for exact transcript matches. Unmapped selections ask for a family recording unless approximate Roman TTS is explicitly enabled.

The journal uses local browser storage; family audio uses IndexedDB. No account, API key, analytics service, or course server receives your journal or microphone recordings. Your browser’s voice provider may process synthetic speech text when the selected voice is not local. Keep backups and original recordings.
