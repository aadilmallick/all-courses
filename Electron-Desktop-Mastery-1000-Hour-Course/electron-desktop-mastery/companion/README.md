# Atlas Desk reference companion

Run `npm test` with Node 24 or newer. Tests have no external dependencies. Run `npm install` and `npm start` to install the pinned Electron runtime and launch the GUI on a supported graphical desktop. A lockfile is generated by that install; review and commit it in your learning repository. The authoring environment did not resolve or install Electron and does not include an invented lockfile.

This reference implements a trusted local content scheme, a sandboxed renderer, narrow preload methods, sender/frame checks, a deterministic approval/cancellation service and a bounded local activity snapshot. It intentionally performs no real model calls, arbitrary tool execution, auth or payment operations. The `core/auth.mjs` file is a domain experiment, not a provider integration.

The snapshot retains at most 300 events. It demonstrates serialized writes and rename replacement, not a production transactional database or a power-loss durability guarantee. Production work in the course replaces this with a repository, migrations, explicit corruption handling and tested recovery. The demo stores the typed prompt locally; do not put secrets into it.

Read `contracts.d.ts` as the TypeScript renderer contract. Migrate the renderer to React/TypeScript using chapter 01, preserve the bridge contract, and move orchestration into a supervised utility process as taught in chapter 05. The small demo service runs in main only because its timer-driven work is trivial and deterministic.

Tests cover real domain behavior and temporary-file persistence. Browser UI checks use a fake bridge and do not establish Electron runtime security or installed-platform behavior. See the course verification report for actual checks.

Optional browser-only UI check: install Playwright in your own development environment and run `node test/browser-smoke.cjs`. If using a separately installed browser, set `CHROMIUM_EXECUTABLE` to its absolute executable path. This uses a fake bridge and does not launch Electron. The authoring attempt was blocked by the host's socket restriction.

The directly runnable chapter experiments live in `examples/`. Run each with Node. The PKCE example uses a reserved example domain and does not contact a provider.
