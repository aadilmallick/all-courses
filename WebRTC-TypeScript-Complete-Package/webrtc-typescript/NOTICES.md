# Provenance and redistribution notes

The teaching prose, diagrams, worked numbers, TypeScript learning companion, and local helpers were authored for this package. The negotiation controller implements the publicly documented perfect-negotiation pattern; source references and inspiration are identified in the chapters and ledger. No full external article, book, vendor SDK, standards extraction, media asset, or third-party code bundle is redistributed.

Linked documentation, sample repositories, and software retain their own licenses and notices. A reading recommendation does not grant permission to mirror their content. The optional LiveKit dependency is not bundled; consult its package license and preserve its actual notices if you install and redistribute it. The core uses browser APIs and Node built-ins without third-party npm dependencies.

Examples use synthetic data and reserved example domains. Any credential secret in tests is explicitly synthetic. No service credentials or private source material are included.
